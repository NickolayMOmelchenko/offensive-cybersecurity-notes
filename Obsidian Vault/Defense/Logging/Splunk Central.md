
**Components of Splunk:**

1. **Forwarders:**
    - Splunk forwarders are lightweight components that collect and forward data to the Splunk indexers.
2. **Indexers:**
    - Indexers store and index the data received from forwarders, making it searchable.
3. **Search Heads:**
    - Search heads are responsible for handling user queries, executing searches, and presenting results.
4. **Deployment Server:**
    - The deployment server manages configurations across multiple instances of Splunk.SPL (Search Processing Language)
